A cat's own five-second defense after knocking a glass off the table: no apology, no guilt — just cat logic. The glass was squatting in the cat's sunbeam and refused to move, so it got evicted. `main.py` (Python standard library only, no network) writes the single-sentence entry to `/output/entry.txt`, deterministically.

## Run it

```bash
python3 main.py
```
